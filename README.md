## Selected projects

### [Formula Pit Wall](https://github.com/AlejandroRenalias/Formula)

A hybrid deterministic + multi-agent Formula 1 strategy system.

It combines race data, deterministic strategy models, provenance tracking, and selective LLM reasoning to simulate pit-wall strategy decisions.

**Built with:** Python · FastF1 · Pydantic · Streamlit · Plotly

### [autoflows](https://github.com/AlejandroRenalias/autoflows)

A collection of automation workflows built with n8n, APIs, JavaScript, AI models, and messaging integrations.

## How I build

I'm especially interested in building software where AI agents operate inside **clear boundaries** rather than simply being asked to generate everything.

That means using:

- clear specifications and contracts
- automated tests
- continuous integration
- independent review
- deterministic logic where appropriate
- AI reasoning where it actually adds value
